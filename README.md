# Balloon Animal Studio

An interactive 3D studio for configuring jewel-like balloon animal sculptures. The project presents a rotatable Balloon Dog and Balloon Rabbit in an experimental editorial interface.

**Live site:** [my-configurator-iota.vercel.app](https://my-configurator-iota.vercel.app)

## Features

- Switch between Balloon Dog and Balloon Rabbit
- Curated full-body and per-part colour compositions
- Jewel glass, glossy vinyl, and chrome surface finishes
- Dog ear, body, and tail form presets
- Mouse/touch rotation and scroll/pinch zoom
- Responsive editorial layout with persistent Light/Dark theme selection

## Technologies

- Vite
- Three.js
- JavaScript
- CSS

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite in your browser. To create a production build:

```bash
npm run build
```

## Status

Working presentation version. The Balloon Dog and Rabbit configurator, material controls, colour controls, responsive layout, and theme toggle are complete; further visual refinements are planned.
